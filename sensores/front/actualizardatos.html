Actualizar Sensor

¿Qué puedes hacer aquí?
Esta página te permite actualizar los datos de un sensor registrado en el sistema. Simplemente ingresa el ID del sensor, los nuevos datos y su unidad de medida. Luego, presiona "Enviar" para guardar los cambios en la base de datos.
Cómo funciona:
  • El campo ID del sensor identifica cuál sensor se actualizará.
  • En Nuevos datos del sensor escribes el nuevo valor medido (por ejemplo, 25.3).
  • En Unidad de medida indicas la unidad (como °C, %, Pa, etc.).
  • Cuando envías el formulario, la información se envía a un archivo para procesarse.
